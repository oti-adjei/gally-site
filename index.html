A few things worth asking

Clear answers.
Small print,
made readable.

Is Gally free?

Yes. No subscription, paid tier or feature paywall is included. “No paywall, ever” is part of the product’s promise.

Can I use it on my computer and phone?

Yes. This web version adapts to desktop, tablet and mobile browsers. Your ledger belongs to the browser and device you use; it does not automatically sync between them. Native iOS and Android designs are prepared, but no App Store or Google Play download is offered in this build.

Where does my money data live?

In this browser’s local storage, when available. Gally does not require an account or bank login and this build sends no money data to a server. Browser storage is not an encrypted vault or a native SQLite file. Clearing site data can remove it, so keep an exported backup.

Does it work without a connection?

Calculations and interactions run locally with no remote dependency. Downloaded project files can run locally. An ordinary hosted page still needs its files to load; an installable offline cache is not included in this build.

Is “Talk it through” a live AI assistant?

Not in this build. It uses clearly labelled guided questions and local calculations. The voice interaction accepts an example transcript; it does not record audio. Live AI and on-device speech need a separate privacy-conscious implementation.

Will Gally charge or cancel my subscriptions?

No. Gally tracks plans, renewals and payments you confirm. Recording a cancellation changes the forecast; you still need to cancel directly with the provider. Reminder preferences are stored here, but OS notification delivery is not connected.

Can I leave with my data?

Yes. Export active transactions as CSV, or download the full browser model as JSON, including your plans and soft-deleted history. Restoring a backup replaces the current ledger after explicit confirmations. Keep the backup somewhere you control.
